Some sample code:

    #!/usr/bin/python
    from pathlib import Path
    a = 0

    print("Hello World")

This also works:

    #!python
    from pathlib import Path
    a = 0

    print("Hello World")

More code:

    :::python
    from pathlib import Path

    print("Hello World")
